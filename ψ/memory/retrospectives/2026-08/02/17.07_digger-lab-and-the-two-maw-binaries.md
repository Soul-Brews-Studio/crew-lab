`maw hey` told me *twice*, in plain text, that the pane it delivered to was running `zsh`
and was "likely misaddressed." Both times I treated it as a targeting nuisance — something

## Honest Feedback

**`maw split` silently starts a second engine.** It reads the anchor pane's
`#{pane_current_command}` and reuses it, so splitting an agent's window spawns another
`oh-my-codex`. I only caught it because the pane count went to 3 and I checked process
start times — the duplicate was 45s newer than the real agent. Nothing in the output says
a second engine was launched.

**A `set -e` guard killed my own script with zero output.** `[ -z A ] || [ -z B ] && {
exit 2; }` returns 1 when both vars are set, so the script exited before doing anything,
printing nothing. "No output" reads exactly like "nothing happened" — I had to check tmux
state to learn that nothing had in fact spawned. That one is entirely mine, not the shell's.

**The timestamp-miner subagent went idle without returning data — second time this
channel has under-delivered.** I ran the extraction myself instead of re-spawning, and
skipped the miner entirely this retro. Also cost a round trip: the `Workflow` tool rejected
`run_in_background`, which it defaults to anyway.

## Lessons Learned

**A warning that fires on both the broken and the working case discriminates nothing — but
a warning that fires only when you have broken something is a finding, not noise.** `maw
hey` warned twice while genuinely misdelivering. I dismissed it because I had already
decided the layout was fine.

**Don't hand-edit a topology another tool addresses by name.** If a system resolves a
resource by a name it generated, reshaping that resource silently severs every consumer,
while the visual result looks untouched. Change it where it is generated, or add *inside*
the named container.

**A tool that defaults to "current context" will pick the wrong one in automation.**
`tmux break-pane` with no `-t` targets the attached session — which in an agent's hands is
the human's own workspace. Always name the target explicitly.

**"Works interactively, fails in a script" means the environments differ — find the
difference before theorising.** Here it was two binaries of the same name; the interactive
one worked only because a later profile line happened to re-prepend its directory.

**Verify a peer's fix on the branch you did *not* report as primary.** Full write-up in
`ψ/memory/learnings/2026-08-02_reporter-shapes-the-fix.md`.
